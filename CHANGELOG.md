# Changelog

## 1.1.0

### Added

- Added top and bottom dot positions
- Top and bottom dots are displayed horizontally
- Bottom dots replace the native Windows running indicator and show from one running window

### Improved

- Left, right, and top dot positions keep the native Windows running indicator unchanged
- Windows task progress indicators remain untouched
- Improved bottom-dot indicator handling and cleanup

## 1.0.0

### Added

- Initial release
- Number badges showing the number of windows represented by each taskbar app button
- Optional compact dot indicators
- Circle, rounded-square, and square badge shapes
- Configurable badge size, position, offsets, colors, border, and font
- Configurable maximum displayed count with `+` for larger values
- Configurable dot size and color
- Live count updates as windows are opened and closed
- Multiple-monitor and secondary-taskbar support
